# 2026-11-02 仮想ユーザー1,000人シミュレーション（実ユーザー調査ではない）

## 方法
- 分布は公開調査の数値を使用:
  - MS-Japan 2025（n=392）: 時間の確保が難しい 56.9%、モチベーションの維持 56.4%、教材費 24.9%、学習方法が分からない 21.8%、無料動画で学習 54.2%
  - トライズ 2025（n=1,103）: 何を学べばよいか分からない 30.9%、無料・低価格 62.5%、短時間の教材 41.9%、自分に合った提案 38.2%、ITスキル 35.6%、資格 31.8%
  - リクルートEd-tech総研 2024（n=400）: 継続的に学習している 35.2%
- 心理特性（現在バイアス・選択過多・進捗フィードバック欲求・損失回避）と「機能→ニーズ」の対応は**仮定**（スクリプト参照）。
- 実サイトの機能有無は manapick.app を375pxで実測（site-task-check.json）。ホームの時間絞り込みは「条件で絞り込む」内にあるため一部充足として扱った。

## 結果（足りない機能、最大3つ選択）
| 割合 | 機能 |
|---|---|
| 82.6% | 学習プランで「できた」→次の動画・翌週のプラン |
| 57.8% | 合計学習時間 |
| 40.8% | ジャンルページなどで時間で絞り込み |
| 34.0% | ホーム以外から検索 |
| 29.4% | 1.5倍速時の時間 |
| 14.7% | 機種変更時の引き継ぎ |

## 追加したもの
- 学習プラン: 学習日ごとの「できたら押す」（視聴済み・連続学習日数に記録）、今週の達成数、完了後「次の7日を作る」（見た動画を除外、第N週）、プラン外で見た動画を除いて組み直す
- マイページ: 合計学習時間（視聴済み動画の長さの合計）
- ジャンル・サブトピックページ: 時間で絞る（〜10分／10〜30分／30分〜）
- メニュー（スマホ）とフッター（全ページ）に動画検索。ホームが ?q= / ?time= を受け取る
- 動画ページ: 1.5倍速時の目安時間

## 限界
- 実在ユーザーの回答ではない。優先順位の仮説として扱い、GA4のイベント（study_plan_session_done / study_plan_next_week / duration_filter）で実際の利用を確認する。
