## 姉妹サイトへの導線（content/network-related.json）

- ネットワーク欄（NetworkContextBand）を、サイト名だけのリンクから「関連する資格・仕事・学習に使うAI・企業」の個別ページへのリンクに変えた。ジャンル単位の既定値に、サブジャンル単位の項目を先頭で重ねる（各サイト最大4件）。
- 登録したURLは、各サイトの sitemap.xml にあり HTTP 200 を返すページだけ。表示名は各ページの title（license・career・ai）と、company の llms.txt に載っている社名（証券コード付きの行）から取った。AI-901 は title が問いかけ形式のため、license サイト内で使われている正式名にした。
- 対応関係は、動画ジャンル・サブジャンルの学習内容と、相手ページの主題（資格名・職業名・ツール名・企業の業種）が一致するものだけにした。例：英語→TOEIC・英検・全国通訳案内士／英語を使う営業・翻訳者／NotebookLM・DeepL／三菱商事・伊藤忠商事・三井物産・翻訳センター。IT→基本情報・ITパスポート・生成AIパスポート・G検定／プログラマー・ITコンサルタント・AIエンジニア／富士通・NEC・日立製作所・NTT。
- NTTデータは company.manapick.app に企業ページがないため（llms.txt に該当行なし）、NTT（9432）を載せた。

## 長い説明の折りたたみ（components/FoldSection.tsx）

- 全916ページを375px幅で開き、セクションごとの本文の文字数を数えた（/tmp の監査スクリプト）。140字以上の説明が並ぶ箇所を、初期状態で閉じる折りたたみにした。本文は HTML に残るため検索・AI検索からは読める。
- 動画詳細（745ページ）：「この動画をどう使うか」「この動画を選ぶ前に知っておきたいこと」「7軸の採点コメント」。次に見る1本とロードマップへのリンクは折りたたみの外に出した。中央値の高さ 8,079px → 約5,800px。
- ロードマップ（/guide/、10ページ）：「なぜこの順番か」「つまずきポイントと回避策」「学習プラン例」「この記事でわかること」。結論と各STEPの動画は表示したまま。
- ニュース（57ページ）：公式発表で確認できたことの一覧は表示したまま、詳細の各節を折りたたみにした。中央値 6,105px → 約4,600px。
- ジャンル一覧の「注意して見ていること」、トピック別ページの全動画一覧、YouTube学習ガイドの「有料教材は…」も同様。
- 残した長めの文（140〜220字）は、ページの結論・答え（「まず何をすればいい？」「結論」「まず何から始める？」）と、規約系ページ（プライバシーポリシー等）。
